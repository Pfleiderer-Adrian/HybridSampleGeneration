# Study

| Parameter | Type | Default | Allowed values | Meaning |
| --- | --- | --- | --- | --- |
| `config.study.name` | `str` | `required at construction` | — | Study name supplied when creating Configuration. |
| `config.study.folder` | `str` | `results/<study name>` | — | Directory for the database, models, and generated artifacts; defaults to results/<study name> in the working directory. |
| `config.study.seed` | `int` | `42` | — | Seed for reproducible random decisions. |
